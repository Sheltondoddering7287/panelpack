## 🛠️ Customizing Your Layout

You can change how your figure looks using the settings menu.

- **Rows and Columns:** You can define how many images appear on each line. If you have six images, you might choose a layout of three images per line in two rows.
- **Labels:** The software adds labels automatically. You can toggle these labels on or off if you prefer a clean look without the A, B, or C marks.
- **Size Calculation:** If you are preparing images for a journal, the tool provides guidance on the correct dimensions. This helps prevent blurry text when you resize your images for publication. Use the "Calculate" feature to see the recommended width and height for your specific output.

## 💡 Pro Tips for Better Figures

To get the best results, keep these tips in mind:

- **Consistency:** Try to use images of similar resolution. Mixing high-resolution images with very low-resolution thumbnails can produce uneven results.
- **Cropping:** The software includes an auto-crop feature. Use this if your original images have large white margins. It keeps the final document clean and saves space.
- **Order:** If the automatic ordering is incorrect, rename your files with prefixes like 01_A, 02_B, 03_C. The tool reads these numbers to determine the sequence.
